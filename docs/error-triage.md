# エラートリアージ台帳

`/logs`(`.claude/skills/logs/SKILL.md`)が使う、エラー fingerprint ごとの判断記録。
手で直してもよい。判断の履歴は git に残る。

状態と再浮上のルール:

- **無視** — 再提示しない(件数だけサマリに出る)
- **様子見** — 判定日より後に発生があれば再提示
- **対応中** — 対応する TODO 項目が `DONE.md` に移ったら修正済み化を提案
- **修正済み** — 修正日より後に発生があれば「再発」として再オープン提案
