# ライブラリのヒーロー曲を下のリストに重複表示しない

## 目的・背景

iOS アプリのライブラリ画面は、当日生成の最新曲を「今日の一曲」ヒーローとして上部に大きく出し、その下に全曲を日付グループで並べる。現状は日付グループが全 `tracks` から組み立てられているため、ヒーローに出した曲が「今日」グループの先頭にもう一度出て、同じ曲が画面に 2 回並ぶ。

## 対応方針

`ios/DailyAIMusic/Sources/Views/TrackListView.swift` の `dayGroups` で、`todayTrack`(ヒーロー曲)と同じ id の曲をグループ化から除外する。

- 当日の曲が 1 曲だけの日は「今日」グループ自体が消える(ヒーローだけになる)。これは期待どおり
- ヒーローが出ない日(当日生成が無い日)は従来どおり全曲がグループに出る(`todayTrack` が nil なので除外は発動しない)
- 再生キューは変更しない — `playOrToggle` はこれまでどおり `tracks` 全体(新しい順)をキューにする。ヒーローはキュー先頭側にあり、表示順とほぼ一致するため

## 影響範囲

- `TrackListView.swift` の `dayGroups` のみ。サーバー・API・他画面への影響なし

## テスト方針

- シミュレータビルド(`xcodebuild build`)が通ることを確認
- ロジックが単純な 1 条件のため、目視確認は実機反映時に行う
