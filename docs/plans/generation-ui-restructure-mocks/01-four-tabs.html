案1 参照曲を独立タブに(4 タブ)

タブを「ライブラリ / 生成 / 参照曲 / 設定」の 4 つにする。生成タブは「おまかせ / 曲を選んで生成」の 2 本に整理し、「アーティストから / 曲名から」という探し方の分岐と管理機能(登録・有効/無効)を参照曲タブへ分離する。ビジュアルは決定済みの案A ミニマルのまま。

案2 3 タブのまま整理 →
長所: 「つくる」と「候補を管理する」がタブで完全に分かれ、名前と中身が一致する。参照曲の有効/無効を整えたいとき生成の導線をたどらなくてよい。
短所: タブが 1 つ増える。参照曲タブは使用頻度が低い(登録・整理は時々しかしない)割に一等地を占める。
新規: 「曲を選んで生成」画面(有効な参照曲の横断リスト。要 GET /api/reference-songs)。曲一覧は行タップ = 有効/無効、生成は「生成」ボタンで明示(現状のタップ = 生成から主従を逆転)。
