# Suno 連携方式の調査プラン

## 目的・背景

daily-ai-music は Suno で音楽を生成し、iPhone(ネイティブアプリ)から操作・再生するアプリ。バックエンド(TypeScript/Node.js)から Suno に生成リクエストを送る必要があるが、連携方式(公式 API の可否、認証方法)が未確定のため、実装前に選択肢を調査して方針を決める。MCP サーバの存在も報告されているため、それも調査対象に含める。

## 調査項目

1. **公式 API の可否**: Suno が公式に開発者向け API を提供しているか。提供している場合の認証方法・料金・利用条件
2. **MCP サーバ**: Suno 公式またはコミュニティの MCP サーバの有無、機能、認証方法
3. **非公式 API / サードパーティ API**: gcui-art/suno-api(Cookie ベース)、sunoapi.org、useapi.net、PiAPI 等の現状・認証方法・料金・リスク(ToS 違反、アカウント BAN)
4. **各方式の比較**: 毎日の自動生成(スケジュール実行)と手動リクエストの両方に耐えるか(安定性・レート制限・コスト)

## 対応方針

- Web 検索と公式ドキュメントの確認で情報収集する
- 調査結果は `docs/specs/suno-api.md` にまとめ、推奨方式を提示する
- 方針が決まったら CLAUDE.md の「未確定事項」を更新する

## 影響範囲

- ドキュメントのみ(`docs/specs/suno-api.md`、`CLAUDE.md`、`TODO.md` / `DONE.md`)。コード変更なし

## テスト方針

- 調査タスクのためテストなし。可能なら公式ドキュメント・料金ページ等の一次情報 URL を根拠として記録する
