# 管理画面の評価ボタンの押下状態を分かりやすくする

## 目的・背景

管理画面の楽曲一覧の 👍/👎 評価ボタンは、選択済みでもピルの背景がアクセント色になるだけで、
絵文字自体は未選択・選択済みどちらもフルカラーで描画されるため、押したかどうかが分かりにくい。

## 対応方針

CSS のみで状態差を強調する(`server/public/style.css` の `.rate-btn`)。

- **未選択**: 絵文字をグレースケール化(`filter: grayscale(1)`)+ 減光(`opacity`)して「押されていない」ことを明示
- **選択済み**: フルカラー絵文字 + アクセント色の背景(現行)で「押されている」ことを明示
- hover は既存どおり枠線をアクセント色に(グレースケールは維持し、全ボタン共通の
  `button:hover { filter: brightness(1.05) }` の上書きも従来どおり打ち消す)

JS のトグルロジック(`.active` クラスの付け外し)は変更しない。iOS アプリは対象外。

## 影響範囲

- `server/public/style.css` のみ(`.rate-btn` 系のルール)

## テスト方針

- ヘッドレス Chrome で楽曲一覧のスクリーンショットを取得し、選択済み(既存データに 👍 あり)と
  未選択のボタンの見た目の差を確認する
