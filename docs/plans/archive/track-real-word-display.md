# 曲にリアルワードの指示文ではなく具体的なワードを表示する

## 目的・背景

楽曲詳細の「LLM への入力全文」の末尾(出力条件)に
`- realWorldWords: この曲の中心となった語(…)を英語小文字で 5〜8 個` という**プロンプトの指示文**が
表示され、具体的なワードが曲に出ていないように見える。実際のワードは詳細内の「リアルワード」
セクションにあるが目立たない。

## 対応方針

1. **プロンプトから指示行を削除**(`llm.ts` の `buildSongPlanPrompt` の出力条件):
   `realWorldWords` の出力指示は構造化出力スキーマの description に同内容があり重複している。
   削除しても LLM への指示は維持され、記録される LLM 入力全文からこの行が消える
   (既存曲の記録は履歴なのでそのまま)
2. **曲の行に実際のワードをタグ表示**(`app.js` / `style.css`):
   評価ボタンの下に小さなピル型タグで `realWorldWords` を並べる(展開不要で見える)。
   ワードが無い旧データはタグ行ごと非表示。詳細内の「リアルワード」セクションは
   全パラメータの記録として存置

## 影響範囲

- `server/src/llm.ts`(出力条件の 1 行削除)
- `server/public/app.js` / `style.css`(タグ表示)
- iOS・API・DB は変更なし

## テスト方針

- `buildSongPlanPrompt` の出力に `realWorldWords:` 行が含まれないこと(単体)
- ヘッドレス Chrome で楽曲一覧にワードタグが表示されること(旧データ行はタグ無し)
- `npm run typecheck`
