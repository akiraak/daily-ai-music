# 生成フォームのプリセット選択の視認性改善

## 目的・背景

管理画面「音楽を生成」上部のプリセット選択チップが見づらい。原因:

- カテゴリラベル(ジャンル・楽器・ムード・テンポ)が行頭に小さく付くだけで、チップが折り返すと
  2 行目以降がラベルの下まで回り込み、カテゴリの境界が視認できない
- カテゴリ間の余白が無く、37 個のチップがひと塊の「壁」に見える

## 対応方針

1. **`server/public/app.js`**: `renderGeneratePresets` でチップ群を `<div class="chips">` に包む
   (ラベル列とチップ列を分離できる DOM 構造にする)
2. **`server/public/style.css`**:
   - `.chip-row` をラベル固定幅 + チップ列の 2 カラムにし、折り返したチップがチップ列の中で揃うようにする
   - カテゴリ行間の余白を広げてグループ境界を明確にする
   - ラベルの文字サイズをわずかに上げ、チップの上下パディングも少し広げて読みやすくする

## 影響範囲

- `server/public/app.js` / `style.css` のみ(API・DB・iOS への影響なし)

## テスト方針

- `node --check` で構文確認
- ヘッドレス Chrome のスクリーンショットでビフォー/アフターを比較し、カテゴリ境界が判別できることを確認
