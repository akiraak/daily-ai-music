# 管理画面からポイントチャージ画面へのリンク

## 目的・背景

管理画面ヘッダーには残クレジット(kie.ai のポイント)が表示されるが、残りが少なくなったときにチャージ画面へ移動する導線がない。ヘッダーにチャージ画面(kie.ai の課金ページ)へのリンクを追加し、ワンタップでチャージに進めるようにする。

## 対応方針

- リンク先は `https://kie.ai/billing`(kie.ai ログイン後のクレジット購入ページ。未ログイン時はログインへ誘導される)
- `server/public/index.html` のヘッダー右側を「残クレジット表示 + チャージリンク」の 2 要素にする
  - リンクは `target="_blank" rel="noopener"` で別タブに開く
  - クレジット取得に失敗して残数が空表示でも、リンクは常時表示されて導線が残るようにする
- `style.css` にヘッダー右側のレイアウト(横並び)とリンクの見た目を追加
- プロバイダ抽象化(`SunoClient`)へのチャージ URL 追加はしない — 現状プロバイダは kie.ai 固定運用で、公式 API へ差し替える際にリンク先も見直せば足りるため

## 影響範囲

- `server/public/index.html`(ヘッダー)
- `server/public/style.css`(ヘッダーまわりのスタイル)
- サーバー・iOS アプリへの変更なし

## テスト方針

- サーバーを起動し `http://localhost:3014/admin/` でリンクが表示されること、クリックで kie.ai の課金ページが別タブに開くことを確認
- `npm run typecheck` が通ること(TS 変更なしの確認)
