# アプリ名の変更

## 決定(2026-08-08)

新名称: **Music Plant** — 「AI が毎日音楽を製造する無機質な工場」のイメージが自動生成に合うため。plant の「植物」の読み(評価で育つ)は副次的な含みとして残る。

変更したのは表示名のみ:

- iOS ホーム画面表示名(`CFBundleDisplayName`)
- 管理画面 3 ページの `<title>` とサイドバーのアプリ名
- 起動ログ・README・CLAUDE.md

内部識別子は据え置き: bundle id `com.akiraak.dailyaimusic`(変更すると実機で別アプリ扱いになり設定が消える)、Xcode プロジェクト名 `DailyAIMusic`、リポジトリ名 `daily-ai-music`、ドメイン `music.chobi.me`、`server/package.json` の名前。

## 目的・背景

現在の名前 `daily-ai-music` / `DailyAIMusic` は機能説明的な仮名。App アイコン作成・iOS デザインの前に、プロダクトとしての名前を決める。

アプリの特徴(名前に反映したい要素):

- 毎日 1 曲、朝に自動生成される(「毎日」「朝」「日々」)
- ニュース・天気など「今日のコンテキスト」を織り込む(「その日をうたにする」= 音の日記・音の暦)
- リアルワードの使用制限で同じ曲は二度と生まれない(一期一会性)
- iPhone でひとりで聴くパーソナルな体験

## 対応方針

- Step 1: 名前を決める(候補 20 案から選定。下記リスト)
- Step 2: リネームの実施
  - iOS: `project.yml`(アプリ表示名・bundle id)、XcodeGen 再生成
  - 管理画面: サイドバーのアプリ名表記(3 ページに複製あり)
  - リポジトリ名 / ディレクトリ名 / CLAUDE.md・README の表記(必要に応じて)
  - 本番ドメイン `music.chobi.me` は変更するか据え置くか要判断

## 影響範囲

- `ios/project.yml`(表示名・bundle id — bundle id 変更は実機上「別アプリ」扱いになる点に注意)
- `server/public/*.html` のサイドバー表記
- ドキュメント類(CLAUDE.md / README / docs)

## テスト方針

- iOS: シミュレータビルドが通り、ホーム画面の表示名が新名称になること
- 管理画面: 3 ページのサイドバー表記が揃っていること(ヘッドレス Chrome でスクショ確認)

## 名前候補(20 案)

### 日本語・和語系

1. **音日記(オトニッキ / OtoNikki)** — その日のニュース・天気を曲にする=「音でつける日記」。コンセプト直結
2. **音暦(オトゴヨミ / Otogoyomi)** — 毎日 1 曲が積み重なって暦になる
3. **音日和(オトビヨリ / Otobiyori)** — 「日和」が天気コンテキストと毎日性を両取り
4. **歌日和(ウタビヨリ / Utabiyori)** — 同上の歌バージョン。歌詞生成が主役なのでこちらも合う
5. **朝音(アサオト / Asaoto)** — 毎朝 6 時に生成される朝の 1 曲
6. **音連れ(オトズレ / Otozure)** — 「訪れ」との掛詞。毎朝、音が訪れる
7. **日々曲(ヒビキョク)/ 響(ヒビキ)** — 「日々」×「曲/響き」の掛詞
8. **一期一音(イチゴイチオン)** — 同じ曲は二度と生まれない一期一会性
9. **泡沫(ウタカタ / Utakata)** — 「歌」を含む語感+その日限りの儚さ
10. **奏日(カナデビ / Kanadebi)** — 「奏でる」+「日」の造語

### 英語・造語系

11. **Meloday** — Melody + Day。毎日のメロディ。短く App 名向き
12. **Daytune** — Day + Tune。今日の 1 曲
13. **Songrise** — Sunrise + Song。朝日とともに曲が生まれる
14. **Newsong** — News + New Song。ニュースから新曲が生まれる掛詞
15. **Everytune** — Everyday + Tune
16. **Daily Muse** — 日々のミューズ(着想の女神)。LLM が着想を生む構図に合う
17. **Tuneline** — Tune + Timeline。曲が時系列に並ぶ一覧 UI と合致

### 追加案: 「作られる音楽」系(英語)

- **Music in the Making** — いままさに作られつつある音楽。毎朝の生成プロセスそのもの
- **Freshly Made** — できたての 1 曲が届く感覚
- **Song Bakery** — 毎朝焼きたてのパン屋の見立て。朝 6 時生成と相性が良い
- **Daily Brew** — コーヒーのように今日の一杯が淹れられる
- **Freshly Pressed** — レコードのプレス+搾りたての掛詞
- **Today's Batch** — 今日の焼き上がり一窯分。その日限りの一回性
- **Song Foundry** — 鋳造所。素材(ニュース・天気・好み)を溶かして曲を鋳る
- **Tunesmith** — 鍛冶屋の音楽版。AI が曲を打つ職人
- **Tailored Tunes** — 好みプロファイルで仕立てられた曲
- **Born Today** — 今日生まれた曲。一期一会性が最も強い

### 検討済み: ミュージックスタンド

英語第一義は「譜面台」だが、日本語の「スタンド」はコーヒースタンド・新聞スタンド的な「毎日立ち寄る小さな売り場」の読みができ、体験のメタファーとしては合う。表示名を英字「Music Stand」にすればホーム画面での省略も避けやすい。

### 既存資産・パーソナル系

18. **Chobi FM / chobi radio** — 本番ドメイン music.chobi.me と一貫。「毎朝届くパーソナルラジオ」の見立て
19. **Chobitune** — 同上の短縮造語
20. **きょうのうた(Kyou no Uta)** — 直球でわかりやすい。ひらがなでアイコン映えも良い
