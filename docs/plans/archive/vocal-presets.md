# 歌手の特徴(歌声)のパラメータ化

## 目的・背景

現状のプリセットはジャンル・楽器・ムード・テンポの 4 カテゴリで、歌手の声の特徴(性別・声質・年齢感)は LLM 任せになっている。歌声もパラメータ(プリセット)として指定・選択できるようにし、毎日の自動生成でできるだけ広い声色をカバーする。

## 対応方針

既存のプリセット機構(DB プール + LLM が選ぶ / ユーザーが選ぶ)にそのまま乗せる。新しい仕組みは作らない。

1. **プリセットに新カテゴリ `vocal`(歌声)を追加**(`server/src/presets.ts`)
   - `CATEGORY_LABELS` に `vocal: "歌声"` を追加
   - SEED_PRESETS に広い声色をカバーする初期セット約 20 件を追加。軸は
     性別(女/男)× 声質(クリア・ハスキー・パワフル・ウィスパー・ファルセット等)× 年齢感(若い〜大人)+ アンサンブル・特殊系(デュエット・聖歌隊・子ども合唱・オペラ・ボコーダー)
2. **シーディングをカテゴリ単位に変更**(`server/src/index.ts`)
   - 現状は「presets テーブルが空のときだけ全件投入」のため、既存 DB に新カテゴリが入らない
   - 「SEED_PRESETS のカテゴリごとに、その カテゴリの行が DB に 1 件も無ければそのカテゴリ分だけ投入」に変更(既存カテゴリ内でユーザーが削除したものは復活しない)
3. **LLM プロンプトに歌声の指示を追加**(`server/src/llm.ts` の `buildSongPlanPrompt`)
   - 出力条件に「インストゥルメンタルでない場合、style に歌手の声の特徴(性別・声質・年齢感)を必ず含める。直近の生成スタイルと歌声が偏らないよう幅広い声色を試す」を追加
   - manual でユーザーが vocal プリセットを選んだ場合は既存の「必ず反映する」セクションでカバーされる

## 影響範囲

- `server/src/presets.ts` — カテゴリラベル + 初期セット追加
- `server/src/index.ts` — シーディングのカテゴリ単位化
- `server/src/llm.ts` — プロンプトの出力条件 1 行追加
- `docs/specs/music-generation.md` — プリセットのカテゴリに歌声を追記
- DB スキーマ変更なし。管理画面(presets.js)はカテゴリを動的に描画するため変更不要。iOS も変更不要(生成画面は自由テキストのみ、プリセット API は汎用)

## テスト方針

- `npm run typecheck`
- サーバーを起動し、既存 DB(プリセット投入済み)に vocal カテゴリだけが追加投入されることを `/admin/api/presets` で確認
- `buildSongPlanPrompt` の出力に歌声の指示が含まれることをスクリプトで確認
- 管理画面のパラメータ一覧に「歌声 (vocal)」グループが表示されることをヘッドレス Chrome で確認
