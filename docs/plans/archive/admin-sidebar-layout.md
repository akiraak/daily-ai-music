# 管理画面を左ペインメニューの一般的なレイアウトに変更する

## 目的・背景

管理画面は現在ページ上部のヘッダー(タイトル+テキストリンク)でページ間を行き来する構成。
ページが 3 枚(楽曲一覧・パラメータ一覧・設定)に増え、今後も増えうるため、
一般的な管理画面レイアウト(左サイドバーにメニュー、右にコンテンツ)へ変更する。

## 対応方針

- **サイドバー**: 左に固定幅(約 210px)のサイドバーを置き、アプリ名+縦並びメニュー
  (楽曲一覧 `/admin/` / パラメータ一覧 `presets.html` / 設定 `settings.html`)を表示。
  現在ページのリンクはアクセント背景でハイライト(`class="active"` を各ページで静的に付与)
- **テンプレートは導入しない**: 静的 3 ページなのでサイドバーのマークアップは各 HTML に複製する
  (テンプレートエンジン・ビルドステップを増やさない方針を維持)
- **コンテンツ側**: 各ページ先頭に `.page-header`(h1+ページ固有の付随情報)。
  残クレジット+チャージリンクは従来どおり楽曲一覧ページのみ(`app.js` の id は変えない)
- **レスポンシブ**: 700px 以下ではサイドバーを上部の横並びナビに切り替える
  (iPhone からも使うため。既存の 720px コンテンツ幅は維持)
- **CSS**: `.layout`(flex)+ `.sidebar` + `main` の構成に変更。旧 `header` 用スタイルは削除

## 影響範囲

- `server/public/index.html` / `presets.html` / `settings.html`(マークアップ変更)
- `server/public/style.css`(レイアウト・サイドバースタイル追加、旧ヘッダースタイル削除)
- JS(`app.js` / `presets.js` / `settings.js`)は変更なし(参照 id を維持)
- バックエンド・iOS は変更なし

## テスト方針

- ヘッドレス Chrome で 3 ページのスクリーンショット(デスクトップ幅 1100px、モバイル幅 500px)を確認
  - サイドバーの表示・アクティブハイライト・コンテンツの余白
  - 700px 以下で横並びナビに切り替わること
- 機能面(credits 表示・設定トグル・ワード表)が従来どおり動くこと(DOM の id 不変で担保、
  スクリーンショットで目視)
